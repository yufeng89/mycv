# 1. 小孔成像针孔模型基础坐标系

相机标定的目标是求解相机成像模型中的参数，使三维世界坐标能够准确映射到二维图像坐标。

主要涉及四个坐标系：

  坐标系       符号   说明
  ------------ ------ --------------------------
  世界坐标系   W      描述真实空间中的物体位置
  相机坐标系   C      原点位于相机光心
  图像坐标系   I      位于成像平面
  像素坐标系   P      图像中具体像素位置

转换关系：

世界坐标 → 相机坐标 → 图像坐标 → 像素坐标

# 2. 理想小孔成像数学公式

针孔模型：

$$
Z_c
\begin{bmatrix}
x\\
y\\
1
\end{bmatrix}
=
\begin{bmatrix}
X_c\\
Y_c\\
Z_c
\end{bmatrix}
$$

其中：

  参数       含义
  ---------- ------------------
  Xc,Yc,Zc   相机坐标系三维点
  x,y        归一化图像坐标
  Zc         深度距离

透视投影：

$$
x=\frac{X_c}{Z_c}
$$

$$
y=\frac{Y_c}{Z_c}
$$

# 3. 相机内参矩阵

内参描述相机自身属性，与外部环境无关。

矩阵：

$$
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
$$

参数说明：

  参数   含义
  ------ -----------
  fx     x方向焦距
  fy     y方向焦距
  cx     主点x坐标
  cy     主点y坐标

像素坐标：

$$
\begin{bmatrix}
u\\
v\\
1
\end{bmatrix}
=
K
\begin{bmatrix}
x\\
y\\
1
\end{bmatrix}
$$

# 4. 相机外参矩阵

外参描述相机在世界坐标中的位置和姿态。

公式：

$$
P_c=RP_w+t
$$

齐次形式：

$$
\begin{bmatrix}
X_c\\Y_c\\Z_c\\1
\end{bmatrix}
=
\begin{bmatrix}
R&t\\
0&1
\end{bmatrix}
\begin{bmatrix}
X_w\\Y_w\\Z_w\\1
\end{bmatrix}
$$

其中：

  参数   含义
  ------ ----------
  R      旋转矩阵
  t      平移向量

# 5. 镜头畸变模型

实际镜头由于光学原因产生畸变。

主要包括：

-   径向畸变
-   切向畸变

## 5.1 径向畸变

由镜头曲率导致。

公式：

$$
x'=x(1+k_1r^2+k_2r^4+k_3r^6)
$$

$$
y'=y(1+k_1r^2+k_2r^4+k_3r^6)
$$

其中：

$$
r^2=x^2+y^2
$$

  参数       含义
  ---------- --------------
  k1,k2,k3   径向畸变系数

## 5.2 切向畸变

由镜头安装偏差导致。

公式：

$$
x'=x+2p_1xy+p_2(r^2+2x^2)
$$

$$
y'=y+p_1(r^2+2y^2)+2p_2xy
$$

  参数    含义
  ------- --------------
  p1,p2   切向畸变系数

# 6. 完整成像流程

完整流程：

$$
P_w
\rightarrow
P_c
\rightarrow
P_n
\rightarrow
P_d
\rightarrow
P_{pixel}
$$

步骤：

  阶段         公式
  ------------ ----------------
  世界到相机   Rc+t
  透视投影     X/Z,Y/Z
  畸变修正     k1,k2,k3,p1,p2
  像素转换     K矩阵

# 7. 参数对比

  参数       作用             是否与相机位置有关
  ---------- ---------------- --------------------
  内参K      焦距、主点       否
  外参R,t    相机姿态位置     是
  畸变参数   镜头非理想因素   否

# 8. OpenCV棋盘格标定代码

安装：

``` bash
pip install opencv-python numpy
```

Python代码：

``` python
import cv2
import numpy as np
import glob


criteria = (
    cv2.TERM_CRITERIA_EPS +
    cv2.TERM_CRITERIA_MAX_ITER,
    30,
    0.001
)

objp = np.zeros((6*9,3), np.float32)
objp[:,:2] = np.mgrid[0:9,0:6].T.reshape(-1,2)


objpoints=[]
imgpoints=[]


images = glob.glob("./images/*.jpg")


for fname in images:

    img=cv2.imread(fname)
    gray=cv2.cvtColor(img,cv2.COLOR_BGR2GRAY)

    ret,corners=cv2.findChessboardCorners(
        gray,(9,6),None
    )

    if ret:

        objpoints.append(objp)

        corners2=cv2.cornerSubPix(
            gray,
            corners,
            (11,11),
            (-1,-1),
            criteria
        )

        imgpoints.append(corners2)


ret,K,dist,rvecs,tvecs = cv2.calibrateCamera(
    objpoints,
    imgpoints,
    gray.shape[::-1],
    None,
    None
)


print("Camera Matrix:")
print(K)

print("Distortion:")
print(dist)
```

输出：

-   Camera Matrix：内参矩阵K
-   dist：畸变参数
-   rvecs：旋转向量
-   tvecs：平移向量
